# EULLM Forge — R&D Roadmap: distillation & verticalization

**Baseline:** Forge pipeline v0.x (prune → distill → quant → identity LoRA → GGUF) · July 2026
**Purpose:** the verticalization *pipeline already exists and runs*, and the **evaluation harness
scaffold now exists too** (see "Current state"). What remains is (a) growing that harness into a
*validated* yardstick and (b) deciding the distillation **recipe** empirically instead of by gut feeling.

Operational document: every item has a checkbox and a tag —
**[✅ done]** already implemented · **[🔧 fix]** exists but needs work/reconciling ·
**[🆕 new]** to be created. An item is "done" only when it meets the Definition of Done at the bottom.

- **Ops scripts** — env setup, dependency install, GPU env check, `train.sh`, `quantize_to_gguf.sh`.
- **Tests** — ~1.5 k LOC (`test_anonymize` 620, `test_italgiure`, `test_dedup`, `test_pipeline`, `test_distill`, `test_eval`, …).
- **1.7B smoke run: PASS.**

### 🔧 To fix / reconcile
- **Run the full-scale 32B → 7B distillation.** Only the 1.7B smoke has actually been executed; no production model has been produced yet (Hub has no models).
- **Reconcile two coexisting recipes.** `pipeline.py` prunes a base then self-distills (Minitron-style, profile `base_model: Qwen3-14B`); `scripts/distill.py` + training configs distil a **32B teacher into a fresh 7B-Base** (no pruning). Decide the canonical recipe.
- **Align teacher declarations.** Profiles say `Qwen3-14B`; strategy/configs say `Qwen3-32B`. Pick one and update the profiles + `CLAUDE.md` ("up to 32B teacher") — e.g. *32B FP8 as KL default, 70B-4bit via SeqKD as the upgrade path*.

- **Forge-generated per-model compliance card** (Annex XI §1 + training summary + copyright + provenance). Not implemented; today the Hub serves a static stub.
- **Membership-inference PII probe** before publishing weights (planned in strategy, not implemented).

## Binding principles
- **Apache-2.0 teacher** (or compatible permissive licence). No Llama in the default catalog.
- **KL only with an identical tokenizer** (same family/vocab, Qwen3 ↔ Qwen3) — else logit-level KL is undefined.
- **Dense, not MoE** for KL (routing adds logit variance).
- **Single-GPU 94–96 GB** reference constraint; a frozen teacher is loaded quantized (70B@4-bit ≈ 35 GB, *lighter* than 30B@FP16 ≈ 60 GB).
- **GDPR-safe dataset**: anonymized corpus only, never raw data.
- **Isolate variables**: one change at a time (teacher size / method), same dataset, same student init, same budget, same seed.
- **Eval before models.**

## Definition of Done (per item)
1. Reproducible: single command + versioned config, idempotent resume-from-checkpoint.
2. Measured: numbers on the F0 eval, not impressions.
3. Recorded: teacher / method / hyperparameters / hours / cost in the model changelog.
4. GDPR-safe: anonymized corpus only; no raw data or PII in the weights (membership-inference probe).
